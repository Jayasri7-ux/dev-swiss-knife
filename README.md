# 🛠️ DevSwissKnife — Developer DevTools Hub

**DevSwissKnife** is a fast, privacy-first, all-in-one developer utility dashboard built with **React**, **Vite**, and **Tailwind CSS**. Every tool runs **100% client-side in your browser**—no tokens, payloads, or secrets ever leave your machine.

---

## ✨ Included Developer Tools

| Tool | Capabilities |
| :--- | :--- |
| **1. JSON Formatter & Validator** | Pretty-print (2 or 4 spaces), minify, key sorting, deep stats (keys, depth, size), and precise syntax error diagnostics. |
| **2. JWT Token Inspector** | Instant Base64URL decoding of `Header`, `Payload`, and `Signature` with human-readable `iat`/`exp` timestamps and live expiration status. |
| **3. Live Regex Workbench** | Real-time pattern matching, inline match highlighting, capture group table, and 1-click presets (Email, URL, IPv4, Hex, Password). |
| **4. Crypto, UUID & Encoding Suite** | Cryptographically secure UUID v4 bulk generator, high-entropy API secret generator with bit-entropy meter, and Base64 / URL encoder-decoder. |

---

## 🚀 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/Jayasri7-ux/dev-swiss-knife.git
cd dev-swiss-knife

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```
